# GameShot Museum — 整体 UI 设计稿

> 参考交互：[rgm.games/games](https://rgm.games/games)（按游戏陈列，点入再展开）。  
> 气质：**展陈式私人游戏馆** · 桌面优先 · 疏朗留白 · 实体盒装封面 · 游戏机感色调 · 明暗记住上次。  
> **无左侧分类栏**；分类若保留，仅作顶栏轻量筛选（可 v1.1）。

---

## 1. 设计结论（一句话）

全宽展柜式浏览：货架上摆着一排**实体游戏盒**，盒间距宽松；点开某盒进入该游戏的截图展墙，再进 Lightbox。不是侧栏档案柜，也不是贴满截图的密集网格。

## 3. 视觉方向

### 3.1 关键词

展陈 · 货架 · 实体盒 · 疏朗 · 主机石板色  
**不是**：左侧分类导航、纸色档案、密铺截图墙、纯 flat 图卡、主机品牌 Logo。

### 3.3 字体

- UI：`IBM Plex Sans` / `Geist`
- 编目：`IBM Plex Mono` 小号
- 无大 Hero 标题

### 3.4 展陈节奏（疏朗）

- 主区左右 padding 桌面建议 `48–64px`，上下 `40–56px`。
- 盒与盒 gap 桌面建议 `28–40px`（宁疏勿密）。
- **默认密度 = 宽松 3 列**（≥1440 可用 3–4；不要默认 5 列）。
- 密度档：大图 2 列 / 宽松 3 / 标准 4；**取消「紧凑 5 列」**或降为高级选项。

### 3.5 首页氛围质感（三层背景 + 扁平底板）

> v1.2 变更：弃用"手柄/主机线稿"显性图案，改为「质感层」方案——加的是材质，不是图案。全部纯 CSS / SVG，零运行时开销，不参与动画（符合第 6 节 transform/opacity 约束）。

#### 层级结构（从底到顶）

```
z-0  Layer 1 · 径向聚光灯      radial-gradient，中央亮四周暗
z-0  Layer 2 · 极淡坐标网格    SVG <pattern>，48px，暗示编目感
z-0  Layer 3 · 微噪点          feTurbulence，胶片颗粒 / 星尘
z-1  Layer 4 · 扁平底板（可选） 圆角 --surface 面板，盒子"摆在展柜里"
z-10 主内容（顶栏 + 盒墙）
```

四层均 `position: fixed; inset: 0; pointer-events: none`（底板除外，仅桌面端、随内容滚动）。

#### 双套参数表

| 层            | 浅色 (Light)                                                                                                    | 深色 (Dark)                                                                                               |
| ------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **L1 聚光灯** | `radial-gradient(ellipse 80% 60% at 50% 22%, var(--bg-elevated), var(--bg) 75%)`                                | `radial-gradient(ellipse 70% 50% at 50% 18%, rgba(94,176,187,0.16), transparent 70%)` 叠在 `var(--bg)` 上 |
| **L2 网格**   | stroke `var(--hairline)`，opacity `0.03`，48px                                                                  | stroke `rgba(232,238,242,0.08)`，opacity `0.02`，48px                                                     |
| **L3 噪点**   | `mix-blend-mode: multiply`，opacity `0.04`                                                                      | `mix-blend-mode: screen`（星尘感），opacity `0.07`                                                        |
| **L4 底板**   | `background: var(--surface)`，`border-radius: 24px`，`box-shadow: inset 0 1px 0 var(--hairline)`，仅 ≥1024 显示 | 同左                                                                                                      |

#### 实现要点

- L1–L3 用单个 `<AmbientBackground />` 组件渲染，挂在 `App.tsx` 根节点最前。
- L2 网格用内联 SVG `<pattern>`，不要引外部图。
- L3 噪点用内联 `<svg><filter id="grain"><feTurbulence type="fractalNoise" baseFrequency="0.9" numOctaves="2"/></filter></svg>` + 一个全屏 `<rect filter="url(#grain)"/>`。
- `prefers-reduced-motion` 不影响这三层（它们本就不动）。
- **禁止**：实体灯具 DOM、百分比标注、粗刻线网格、暖黄画廊灯（spotlight 严格走 token 冷色）。

### 4.1 顶栏

- 左：站点名小字（非 Hero）。
- 中：搜索。
- 右：我的收藏 · 密度 · 主题。
- 无分类侧栏、无大标题、无 CTA。

### 4.2 Level 1 · 实体盒装（核心）

**必须是「盒子」，不是「单纯截图缩略图」。**

结构（竖版约 135:170，无品牌标）：

```text
        ▌← 可选：左侧窄脊（暗示厚度）
┌───────┴────────────────────────┐
│  ░░░░░ 塑胶外壳边框 ░░░░░░░░░  │  ← box-plastic，可见厚度/圆角
│  ┌──────────────────────────┐  │
│  │                          │  │
│  │     封面图（内凹 inset）   │  │  ← 四周留 8–12px 壳边，不要出血铺满
│  │                          │  │
│  └──────────────────────────┘  │
│  ┌──────────────────────────┐  │
│  │ 游戏名                    │  │  ← 盒底标签区（也是壳的一部分）
│  │ 24 shots                  │  │
│  └──────────────────────────┘  │
└────────────────────────────────┘
     ▂▂▂  极轻接触阴影（货架感）
```

盒样式要点：

1. **外壳**：独立塑胶色边框 + 轻微内高光/外暗边，像实体盒子。
2. **封面 inset**：截图嵌在壳内，四周露壳，禁止整张图直接当卡片。
3. **脊线（推荐）**：左侧 6–10px 深色窄条模拟书脊/盒脊，增强「盒子」体积感（CSS 即可，非 3D 模型）。
4. **底托阴影**：很轻的椭圆接触影，像放在展柜层板上。
5. **禁止**：平台 Logo、角标贴纸、纯 flat 无壳截图墙。

交互：

- Hover：整盒 `translateY(-4px)`，阴影略加强；封面微 scale（壳不动或少动）。
- 点击 → `/game/:gameId`。

封面选取：收藏优先 → 否则首张 → 失败则壳色+首字。

### 4.3 Level 2 · 截图展墙

顶栏：`← 馆藏  /  游戏名`  
疏朗网格；v1 建议 16:9 裁切；Hover 星标。  
进入后可关掉首页氛围图案。

### 4.4 Lightbox

全屏查看；键盘切换；信息面板大屏右侧。

### 4.5 我的收藏

顶栏入口；跨游戏截图平铺；空状态一句文案即可。

## 6. 动效（克制）

1. Level1→2：fade + 轻位移 ~220ms
2. 图加载完成：opacity ~280ms
3. 盒 Hover：上浮 + 阴影
4. Lightbox：fade ~200ms
5. 氛围图案：静态或极慢呼吸

只动画 `transform` / `opacity`。
