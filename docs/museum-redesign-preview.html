A · 静物画廊 Gallery Noir

放弃「科技 HUD + 玻璃胶囊」路线，转向真实美术馆：暖金射灯、画框装裱、纸质感暗角。气质像深夜闭馆后独自逛展，而非 SaaS 仪表盘。

  • 主色：炭黑 + 暖金（#c9a227），去掉 teal
  • 顶栏：细线分割编辑栏，非 floating glass pill
  • 封面：实体画框 + 底部暖光，无 3D 透视
  • 字体：Hero 用 Instrument Serif 增加馆藏感

B · 暗场影院 Cinema Noir（修正版）

保留现有「影院银幕墙」记忆点，但修掉廉价感：去掉 HUD 网格/漂浮光斑，用强暗角 + 单一地平线光带营造暗场体积感。3D 透视减弱到 -6deg。

  • 主色：炭黑 + teal（保留现有 accent）
  • 背景：仅 base + horizon + vignette，无 sci-fi 元素
  • 封面：银幕上下边光，去掉 hud-frame 角标
  • 顶栏：保留 glass pill，但背景更深、blur 更强

C · 复古街机馆 Arcade Archive

强调「玩家」身份：街机框体、卡带边框、mono 字体、琥珀色 accent。适合截图量大、偏 Action / RPG 的收藏者，游戏感最强但需控制复古度避免 kitsch。

  • filmstrip 作为核心视觉，像 arcade marquee
